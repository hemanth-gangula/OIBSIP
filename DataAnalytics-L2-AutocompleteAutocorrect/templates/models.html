NLP Models

How each language model and spelling corrector works — their mechanisms, strengths, limitations, and evaluation results.

⚠️

These are statistical language models and algorithmic spelling correctors — NOT neural networks or trained ML classifiers. They use frequency counts and edit distances computed from a text corpus; no gradient-based training occurs.

Language Models (Autocomplete)

Bigram

BigramModel

Purpose
Predict the next word given the single preceding word.
How it works
Counts all consecutive word pairs (bigrams) in the corpus. For a given word w, it looks up all words that followed w in training text and ranks them by Maximum Likelihood Estimate (MLE) probability: P(w₂|w₁) = count(w₁,w₂) / count(w₁).
Strengths
Fast, memory-efficient, simple to interpret, no training step required.
Limitations
Uses only one word of context; misses longer dependencies; data-sparse for rare words.
Evaluation metric
Top-1 accuracy, Top-3 accuracy, Mean Reciprocal Rank (MRR).
Top-1: 30.5 % Top-3: 57.0 % MRR: 0.422
Trigram

TrigramModel

Purpose
Predict the next word given the two preceding words.
How it works
Counts all consecutive word triples (trigrams). Given context (w₁, w₂), ranks candidates by P(w₃|w₁,w₂) = count(w₁,w₂,w₃) / count(w₁,w₂). Falls back to bigram predictions when the trigram context hasn't been seen.
Strengths
Captures richer context than bigrams; significantly higher accuracy on common phrases.
Limitations
Data-sparse for rare word pairs; larger memory footprint; no smoothing implemented.
Evaluation metric
Top-1 accuracy, Top-3 accuracy, Mean Reciprocal Rank (MRR).
Top-1: 65.0 % Top-3: 80.0 % MRR: 0.720

Spelling Correctors (Autocorrect)

Edit Distance

EditDistanceCorrector

Purpose
Find real dictionary words that are closest to the misspelled input.
How it works
Generates all words within edit-distance 1 (single insertion, deletion, substitution, or transposition) and edit-distance 2 of the input word. Filters these against the known vocabulary, then ranks survivors first by edit distance (smaller = better) and second by corpus frequency (higher = better). This is a deterministic algorithm — no probabilities involved.
Strengths
Transparent, interpretable, no ambiguity in ranking logic.
Limitations
Computationally expensive for edit-distance 2; ignores word-frequency weighting at the primary rank; can suggest equally-distant but unlikely words.
Evaluation metric
Top-1 accuracy and Top-3 accuracy on 50 misspelled/correct word pairs.
Top-1: 48.0 % Top-3: 58.0 % n = 50 pairs
Probabilistic

ProbabilisticCorrector

Purpose
Rank candidate corrections by corpus frequency, favouring the most common real word.
How it works
Implements Norvig's spell corrector: generates edit-1 and edit-2 candidates, filters to known vocabulary, and scores each by its unigram probability P(w) = count(w) / total_tokens. Edit-1 candidates are always preferred over edit-2 candidates. This uses the same edit-generation logic as EditDistanceCorrector but ranks primarily by frequency.
Strengths
More likely to surface common words; better for frequent misspelling patterns.
Limitations
Can over-correct to high-frequency words even when a lower-frequency word is the obvious correction. No context from surrounding words.
Evaluation metric
Top-1 accuracy and Top-3 accuracy on 50 misspelled/correct word pairs.
Top-1: 48.0 % Top-3: 58.0 % n = 50 pairs
