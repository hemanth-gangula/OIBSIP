Sentiment Methodology — VADER NLP

Every review was classified fresh using VADER (Valence Aware Dictionary and sEntiment Reasoner), a rule-based NLP model optimised for short-text sentiment. Compound ≥ 0.05 → Positive · ≤ −0.05 → Negative · between → Neutral. The existing Sentiment column is used only as a validation reference.

Sentiment Distribution

VADER Compound Score Distribution

Compound score ranges from −1 (most negative) to +1 (most positive). Dashed threshold lines mark the Positive (+0.05) and Negative (−0.05) boundaries. Hover over any bar to see the exact count for that score range.
